# 🕹️ Jogo P_P_T (Pedra, Papel e Tesoura)

Este é um projeto simples em Python que simula o clássico jogo de Pedra, Papel e Tesoura contra o computador.

## 🚀 Como Executar o Projeto

1. Certifique-se de ter o Python instalado.
2. Clone o repositório ou baixe o arquivo `main.py`.
3. Execute o comando no terminal:
   ```bash
   python main.py
   ```

## 🛠️ Tecnologias Utilizadas
* Python 3
